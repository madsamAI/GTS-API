CPaaS+ lets you reach customers on the channel that works best for them, through a single, consistent REST API. This guide explains how each channel works and how to call it. The **API Reference** tab lists every endpoint with an interactive playground.

## How the API works

| Concept | Detail |
| --- | --- |
| Base URL | Provided at onboarding. Every path in this guide is relative to it. |
| Authentication | Bearer token on every request. See [Authentication](/authentication). |
| Format | JSON request bodies (`Content-Type: application/json`) unless an endpoint says otherwise. |
| Templates | Most channels send from templates you create and get approved in the CPaaS+ web portal. |
| Status | SMS, Email and RCS each expose a status endpoint. |

<Note>
  New to the API? Start with the [Quickstart](/quickstart) to send your first message in a few minutes.
</Note>
