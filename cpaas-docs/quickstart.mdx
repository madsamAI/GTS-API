title: "Quickstart"
description: "Send your first message in four steps."
---

<Steps>
  <Step title="Get your base URL and token">
    Your CPaaS+ base URL is shared at onboarding. Use the API token issued for your account. Keep it server-side and never commit it to source control.
  </Step>
  <Step title="Create a template or campaign">
    In the web portal, create the SMS campaign or template, WhatsApp template, email template or RCS template you want to send. Note its ID.
  </Step>
  <Step title="Send a message">
    The example below sends an SMS using a template. Replace the placeholders with your own values.

    <CodeGroup>
    ```bash cURL
    curl -X POST "$BASE_URL/api/sms/template/send" \
      -H "Authorization: Bearer $API_TOKEN" \
      -H "Content-Type: application/json" \
      -H "Accept: application/json" \
      -d '{
        "alias": "YOUR_TEMPLATE_ID",
        "to": ["919876543210"],
        "params": { "1": "ORD-1001" }
      }'
    ```

    ```python Python
    import os, requests

    resp = requests.post(
        f"{os.environ['BASE_URL']}/api/sms/template/send",
        headers={
            "Authorization": f"Bearer {os.environ['API_TOKEN']}",
            "Accept": "application/json",
        },
        json={
            "alias": "YOUR_TEMPLATE_ID",
            "to": ["919876543210"],
            "params": {"1": "ORD-1001"},
        },
        timeout=30,
    )
    print(resp.status_code, resp.json())
    ```

    ```javascript Node.js
    const resp = await fetch(`${process.env.BASE_URL}/api/sms/template/send`, {
      method: "POST",
      headers: {
        Authorization: `Bearer ${process.env.API_TOKEN}`,
        "Content-Type": "application/json",
        Accept: "application/json",
      },
      body: JSON.stringify({
        alias: "YOUR_TEMPLATE_ID",
        to: ["919876543210"],
        params: { 1: "ORD-1001" },
      }),
    });
    console.log(resp.status, await resp.json());
    ```
    </CodeGroup>
  </Step>
  <Step title="Check delivery status">
    Use the status endpoint for the channel (for example `GET /api/sms/status`) with the message ID from the send response.
  </Step>
</Steps>

<Tip>
  You can also try any endpoint directly from the **API Reference** tab: paste your token into the playground's authorization field.
</Tip>
